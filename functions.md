# Атомарные функции системы CRM НКО

## 1. Функции регистрации и аутентификации

### 1.1 Регистрация нового физического лица
- Создание новой записи о ФЛ в базе данных
- Генерация уникального идентификатора ФЛ
- Валидация регистрационных данных
- Отображение сообщения об успешной регистрации
- Перенаправление на личный кабинет после регистрации

### 1.2 Аутентификация пользователя
- Проверка учетных данных ФЛ
- Сравнение введенного пароля с хэшем из базы данных
- Генерация и управление сессией пользователя
- Отображение ошибок аутентификации
- Логирование попыток входа

### 1.3 Вход в личный кабинет
- Проверка активности сессии
- Валидация прав доступа пользователя
- Открытие личного кабинета ФЛ
- Отображение основной информации о пользователе

## 2. Функции управления документами

### 2.1 Создание персональной папки
- Создание структуры папок для нового ФЛ
- Установка прав доступа к папке
- Генерация уникального пути к папке
- Логирование создания папки

### 2.2 Загрузка документов
- Проверка типа и размера загружаемого файла
- Валидация формата документа
- Сохранение документа в персональной папке
- Обновление метаданных документа (дата, размер, тип)
- Отображение сообщения об успешной загрузке
- Отображение ошибок загрузки

### 2.3 Скачивание документов
- Проверка прав доступа к документу
- Формирование URL для скачивания
- Отображение списка доступных документов
- Логирование операций скачивания
- Предоставление возможности скачивания группой

### 2.4 Управление документами
- Отображение списка документов ФЛ
- Показ метаданных документов (дата создания, размер)
- Поиск документов по имени
- Отображение предпросмотра документов (если поддерживается)

## 3. Функции управления реестрами

### 3.1 Отображение реестра ФЛ
- Получение списка всех ФЛ из базы данных
- Формирование таблицы с основными атрибутами
- Отображение списка в виде таблицы или карточек
- Поддержка пагинации для больших наборов данных

### 3.2 Фильтрация реестров
- Применение фильтров по различным атрибутам
- Объединение нескольких фильтров
- Отображение отфильтрованного списка
- Сброс фильтров

### 3.3 Сортировка реестров
- Применение сортировки по различным полям
- Поддержка прямого и обратного порядка
- Сохранение состояния сортировки
- Отображение отсортированного списка

### 3.4 Поиск по реестрам
- Поиск по ключевым атрибутам ФЛ
- Поддержка частичного совпадения
- Отображение результатов поиска
- Подсветка найденных элементов

## 4. Функции управления доступом

### 4.1 Проверка прав доступа
- Определение роли пользователя (ФЛ, администратор)
- Проверка разрешений на выполнение операций
- Сравнение ролей с необходимыми правами
- Отказ в доступе при отсутствии прав

### 4.2 Управление правами доступа (для администраторов)
- Назначение ролей пользователям
- Изменение прав доступа
- Отображение текущих прав пользователя
- Логирование изменений прав

## 5. Функции уведомлений

### 5.1 Отправка уведомлений
- Определение типа уведомления
- Формирование содержания уведомления
- Выбор канала доставки (email, системные уведомления)
- Отправка уведомления пользователю

### 5.2 Настройка уведомлений
- Отображение настроек уведомлений пользователя
- Включение/выключение типов уведомлений
- Сохранение настроек пользователя

## 6. Функции управления данными

### 6.1 Обновление информации о ФЛ
- Редактирование основных данных ФЛ
- Обновление контактной информации
- Сохранение изменений в базе данных
- Валидация измененных данных

### 6.2 Управление метаданными
- Обновление информации о документах
- Изменение свойств файлов
- Логирование изменений данных

## 7. Сервисные функции

### 7.1 Логирование
- Логирование всех операций пользователей
- Сохранение информации о входах и выходах
- Логирование ошибок системы
- Создание отчетов по активности

### 7.2 Валидация данных
- Проверка корректности вводимых данных
- Валидация форматов файлов
- Проверка допустимых значений полей
- Отображение сообщений об ошибках

### 7.3 Безопасность
- Шифрование персональных данных
- Защита от SQL-инъекций
- Защита от XSS-атак
- Контроль доступа к файлам
