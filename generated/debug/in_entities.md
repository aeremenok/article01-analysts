# Сущности системы CRM НКО

## 1. Физическое лицо (ФЛ)

### Описание
Основной пользователь системы, которому требуется личный кабинет для доступа к своим данным и документам.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **имя** - строка
- **фамилия** - строка
- **отчество** - строка
- **email** - строка
- **телефон** - строка
- **адрес** - строка
- **дата рождения** - дата
- **серия и номер паспорта** - строка
- **кем и когда выдан паспорт** - строка
- **инн** - строка
- **снилс** - строка
- **статус учетной записи** - ENUM (активна, неактивна, заблокирована)
- **дата создания** - дата/время
- **дата последнего обновления** - дата/время
- **последний вход в систему** - дата/время

## 2. Персональная папка

### Описание
Отдельная папка для хранения документов каждого физического лица.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **id_физического_лица** - ссылка на ФЛ
- **путь_к_папке** - строка
- **название** - строка
- **описание** - текст
- **дата создания** - дата/время
- **дата последнего обновления** - дата/время
- **права_доступа** - ENUM (чтение, запись, полный доступ)
- **статус** - ENUM (активна, архивирована)

## 3. Документ

### Описание
Физический документ, загруженный в персональную папку ФЛ.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **id_персональной_папки** - ссылка на папку
- **id_физического_лица** - ссылка на ФЛ
- **название** - строка
- **описание** - текст
- **тип_файла** - строка (например: pdf, doc, xls)
- **размер** - число (в байтах)
- **путь_к_файлу** - строка
- **md5_хеш** - строка
- **дата_создания** - дата/время
- **дата_последнего_обновления** - дата/время
- **статус** - ENUM (активен, удален)
- **метаданные** - JSON (дополнительные атрибуты)

## 4. Администратор НКО

### Описание
Пользователь с правами администратора, управляющий данными клиентов и системой.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **логин** - строка
- **email** - строка
- **имя** - строка
- **фамилия** - строка
- **роль** - ENUM (администратор, суперпользователь)
- **статус** - ENUM (активен, неактивен)
- **дата_создания** - дата/время
- **дата_последнего_обновления** - дата/время
- **последний_вход** - дата/время

## 5. Сессия пользователя

### Описание
Информация о текущей сессии пользователя в системе.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **id_пользователя** - ссылка на ФЛ или администратора
- **token** - строка (токен авторизации)
- **ip_адрес** - строка
- **user_agent** - строка
- **дата_создания** - дата/время
- **дата_последнего_обновления** - дата/время
- **дата_истечения** - дата/время
- **статус** - ENUM (активна, завершена, истекла)

## 6. Реестр физических лиц

### Описание
Системное представление списка всех физических лиц с возможностью фильтрации и сортировки.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **название** - строка
- **описание** - текст
- **дата_создания** - дата/время
- **дата_последнего_обновления** - дата/время
- **создатель** - ссылка на администратора
- **параметры_фильтрации** - JSON (настройки фильтров)
- **параметры_сортировки** - JSON (настройки сортировки)
- **статус** - ENUM (активен, архивирован)

## 7. Уведомление

### Описание
Системное уведомление, отправляемое пользователям.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **id_получателя** - ссылка на ФЛ или администратора
- **тема** - строка
- **содержание** - текст
- **тип_уведомления** - ENUM (системное, документы, другие)
- **дата_создания** - дата/время
- **дата_отправки** - дата/время
- **статус** - ENUM (ожидает, отправлено, ошибки)
- **предпочтения_пользователя** - JSON (настройки уведомлений)

## 8. Права доступа

### Описание
Права и привилегии, назначенные различным ролям пользователей.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **название_роли** - строка
- **описание** - текст
- **массив_привилегий** - массив строк (например: [чтение_данных, запись_данных, удаление_документов])
- **дата_создания** - дата/время
- **дата_последнего_обновления** - дата/время
- **статус** - ENUM (активна, неактивна)

## 9. Лог операций

### Описание
Журнал всех операций пользователей в системе.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **id_пользователя** - ссылка на ФЛ или администратора
- **тип_операции** - ENUM (вход, выход, создание, изменение, удаление)
- **описание_операции** - текст
- **дата_операции** - дата/время
- **ip_адрес** - строка
- **данные_до** - JSON (данные до операции)
- **данные_после** - JSON (данные после операции)
- **успешно** - булево значение

## 10. Поиск по реестрам

### Описание
Настройки и результаты поисковых запросов к реестрам физических лиц.

### Атрибуты
- **id** (уникальный идентификатор) - строка/число
- **id_пользователя** - ссылка на администратора или ФЛ
- **запрос** - строка
- **дата_поиска** - дата/время
- **результаты** - массив объектов (список найденных ФЛ)
- **колличество_результатов** - число
- **параметры_фильтрации** - JSON
- **параметры_сортировки** - JSON
