# Требования к системе CRM

## 1. Stakeholders (роли пользователей)

- **Клиент** — ответственный за функционал системы CRM, требует наличия личных кабинетов для физических лиц и работы с документами.
- **Физическое лицо (ФЛ)** — пользователь, которому требуется личный кабинет на сайте НКО для доступа к своим данным и документам.
- **Администратор НКО** — управляет данными клиентов, физических лиц и обеспечивает работу системы.

## 2. Текущая ситуация (AS-IS)

- В настоящее время существует необходимость создания CRM системы.
- Для каждого физического лица (ФЛ) должна существовать отдельная папка с документами, включая персональные данные (ПД).
- Необходимо формировать реестры из физических лиц с возможностью фильтрации, сортировки и выборки по различным атрибутам.
- У каждого ФЛ должен быть личный кабинет на сайте организации (НКО).

## 3. Функциональные требования

### 3.1 Управление документами

- Создание и хранение папок для каждого физического лица.
- Хранение документов внутри папок ФЛ, включая документы с персональными данными.
- Возможность доступа к документам через личный кабинет физического лица.

### 3.2 Реестры физических лиц

- Формирование реестров из физических лиц.
- Фильтрация реестров по различным атрибутам.
- Сортировка реестров.
- Выборка данных из реестров по заданным параметрам.

### 3.3 Личные кабинеты

- Создание личного кабинета для каждого физического лица.
- Доступ к личному кабинету через сайт организации (НКО).
- Отображение информации о физическом лице и связанных с ним документах.

## 4. Нефункциональные требования

- Безопасность персональных данных (ПД) в соответствии с законодательством.
- Удобство использования интерфейса администратора и пользователей.
- Надежность системы хранения данных.
- Производительность при работе с большими объемами данных.
- Соблюдение стандартов веб-разработки.

## 5. Ограничения

- Система должна быть реализована в рамках существующих технологий НКО.
- Необходимо соблюдать нормы защиты персональных данных.
- Пользователи системы должны иметь доступ к интернету для входа в личный кабинет.
- Ограничения по объему хранимых данных.
